# DESIGN

## Brand
- Name: DeadZone
- One-line mission: "Live crowd intelligence for venues — BLE-first, mesh-ready, privacy-preserving."

## Colors
- Canvas: #000000 (pure black)
- Surface card: #1a1a1a
- Surface elevated: #262626
- Hairline: #3c3c3c
- On-dark: #ffffff
- Body: #bbbbbb
- M tricolor (DeadZone-native, used only as 4px brand stripe — never as fill):
  - M-blue-light: #0066b1
  - M-mesh: #8B5CF6
  - M-red: #e22718
- Accent / "live": #e22718 (M-red)
- Warning: #f4b400

## Typography
- Display: "Inter", 700, uppercase, letter-spacing -0.5px (BMW Type Next Latin substitute)
- Body: "Inter", 300
- Label: 14px / 700 / uppercase / letter-spacing 1.5px

## Motion
- Mood: industrial precision, confident, restrained
- Eases: `power3.out` for entrances, `expo.in` for exits
- Transitions: `flash-through-white` between scenes (BMW M motion-graphics signature)
- No bounce, no elastic, no playful eases

## Assets
- Dashboard (dark): `assets/dashboard-dark.png`
- Heatmap page (dark): `assets/heatmap-dark.png`
- Dashboard (light): `assets/dashboard-light.png`
- Heatmap page (light): `assets/heatmap-light.png`
- Mobile dark: `assets/mobile-dark.png`

## What NOT to Do
- No purple-only or pastel palettes (off-brand for BMW M language)
- No drop shadows on text or chrome
- No rounded buttons — sharp rectangles only
- No serif body, no script display fonts
- No bouncy/elastic motion
- Never use the M tricolor as a button fill or background fill — it's a 4px brand stripe ONLY
